# F-196, Word corpus

**Status**: completed
**Sprint**: S57
**Size**: M
**Depends on**: none

## Problem

Word fidelity currently relies on seven documents generated by this repository,
so it can detect changes against itself but cannot expose disagreement with real
Word documents. `scripts/hash_harness.py:33` fixes that generated inventory.
There is no pinned Word corpus, Word manifest, or Word fetcher.

The Presentation fetcher at `scripts/fetch_pptx_corpus.py:14` verifies paths,
producers, checksums, HTTPS URLs, and complete directory membership. It does not
carry licence identity or category coverage, both of which S57 requires for the
Word corpus.

## Approach

Add `scripts/docx-corpus-manifest.tsv` with the columns `path`, `category`,
`producer`, `licence`, `licence_url`, `sha256`, and `url`. Pin an exact reviewed
entry count and require nonzero coverage for `business-letter`, `report`,
`form`, `legal-revision`, and `multi-script`.

Add `scripts/fetch_docx_corpus.py`, following the existing Presentation fetcher
without sharing an abstraction. It accepts safe leaf `.docx` paths, unique
paths and URLs, an exact approved SPDX licence allowlist, HTTPS source and
licence URLs, and lowercase SHA-256 values. It downloads to a temporary sibling,
checks the digest before replacement, removes partial downloads, and stores the
verified corpus under ignored `corpus/docx`.

The read-only `--check` mode rejects missing, extra, changed, unsafe,
misclassified, or unlicensed inputs. The normal test and MSRV CI jobs fetch the
Word corpus before tests. Existing workflow regressions prove that the steps
are present and fail closed.

## Rejected alternatives

- Commit binary documents. The external corpus is the one fetched-fixture
  exception and remains outside published archives.
- Accept any nonempty licence string. That records text but does not refuse an
  unreviewed licence.
- Generalise the Presentation fetcher first. Two concrete scripts keep each
  corpus contract discoverable and avoid a wrapper that only forwards.

The **test gate** is regression. The fetcher verifies every checksum and refuses
a corpus that does not match.
